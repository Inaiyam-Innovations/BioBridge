APPLICANT PROFILE

Built for Builders, Not Just Pitchers.

The priority applicant: The student team already working on a problem in this space — a project that has been running in a lab, a final-year build, or an idea a team has been circling for months.

Four weeks is enough time to sharpen and package existing work; it is short for starting from zero. The problem statements give those teams a frame to apply through, and give genuinely new teams somewhere to start.

Why zero entry fee is deliberate:

Dropping the registration fee is deliberate. It removes the main reason a serious team from a smaller college self-selects out, and it widens the funnel at the top — which matters when only 50 of the applications carry through to the build phase.
